# Phone rules

Require an AI disclosure line for every request.
Preview calls before live dispatch.
Use live mode only when the user authorizes the call.
Use E.164 numbers and vendor keys from the environment.
Keep calls inside the configured day hours.
Honor caps and the blocklist. Do not change text to bypass a denial.
Report vendor errors as failures.
Read the consent log and session costs after a live call.
Do not retry an uncertain live result until its vendor state is known.
